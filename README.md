# SellerPilot

Premium black-and-gold e-commerce seller SaaS demo for Shark Tank.

## Core demo
1. Upload Meesho-style PDF labels, Excel or CSV.
2. SellerPilot extracts and normalizes order data.
3. Review/edit extracted rows.
4. Enter/adjust cost price.
5. Generate an Excel report.
6. View revenue, cost, profit and margin.
7. Use Seller Assistant for business questions.

## Pricing
